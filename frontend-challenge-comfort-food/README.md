# Warm Table — Refined Landing Page

A polished, image-led landing page created for the **DEV Frontend Challenge: Comfort Food Edition — Perfect Landing**.

## Live Demo

https://zoelinsg.github.io/DEV-Projects/frontend-challenge-comfort-food/

## Source Code

https://github.com/zoelinsg/DEV-Projects/tree/main/frontend-challenge-comfort-food

## Overview

Warm Table is a fictional Taiwanese comfort-soup house built around the idea that a warm bowl of soup can make a difficult day feel a little softer.

The landing page focuses on large food photography, a warm brick-red and cream palette, clear visual hierarchy, and lightweight frontend interactions.

## Soups

- Garlic Chicken Soup
- Peanut Pig Trotter Soup
- Ginger Duck Soup
- Ginger Sea Bass Soup
- Fo-Ti Herbal Chicken Soup
- Astragalus and Angelica Lamb Soup

## Features

- Responsive top navigation
- Daylight and evening themes
- Mood-based soup recommendation
- Six-image soup gallery
- Native email validation
- Accessible navigation states and live feedback
- Reduced-motion support
- Lazy-loaded WebP images
- Responsive layouts for desktop, tablet, and mobile

## Tech Stack

- Semantic HTML
- Modern CSS
- Vanilla JavaScript
- Local WebP image assets
- GitHub Pages

## Design Direction

The final version uses a calmer, more cohesive restaurant experience.

The design focuses on:

- Large soup photography
- Moderate, readable typography
- A simple top navigation
- No section numbering
- English-only interface copy
- A warm brick-red and cream palette
- Clear spacing and consistent card shapes
- A contained visit card with a lightweight footer

## Run Locally

Open `index.html` with VS Code Live Server, or run:

```bash
python -m http.server 8080
```

Then open:

```text
http://localhost:8080
```
