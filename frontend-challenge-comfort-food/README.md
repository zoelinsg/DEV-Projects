# Warm Table — Refined Landing Page

A polished, image-led landing page for the **DEV Frontend Challenge: Comfort Food Edition — Perfect Landing**.

## Design direction

This version replaces the previous numbered editorial layout with a calmer, more cohesive restaurant experience.

The redesign focuses on:

- Large soup photography
- Moderate, readable typography
- A simple top navigation
- No section numbering
- No bilingual labels
- A warm brick-red and cream palette
- Clear spacing and consistent card shapes
- A softer contained visit card with a separate lightweight footer

## Soups

- Garlic Chicken Soup
- Peanut Pig Trotter Soup
- Ginger Duck Soup
- Ginger Sea Bass Soup
- Fo-Ti Herbal Chicken Soup
- Astragalus and Angelica Lamb Soup

## Features

- Responsive top navigation
- Day and evening themes
- Mood-based soup recommendation
- Six-image soup gallery
- Native email validation
- Accessible navigation states and live feedback
- Reduced-motion support
- Lazy-loaded WebP images

## Run locally

Open `index.html` with VS Code Live Server, or run:

```bash
python -m http.server 8080
```

Then open:

```text
http://localhost:8080
```
